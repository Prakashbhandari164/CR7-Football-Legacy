# CR7 Football Legacy

A public-ready, fan-made tribute website and documentation project celebrating Cristiano Ronaldo's football journey and iconic **SIUUU** celebration.

## Preview locally
1. Download and extract this repository.
2. Open `index.html` in a modern browser.
3. Keep the `assets/` folder beside `index.html` so the animated GIF loads.

## What's included
- Responsive black-and-gold tribute website
- Animated SIUUU celebration GIF and original sprite sheet
- Career values and tribute copy
- Documentation in `docs/`

## Publish with GitHub Pages
1. Create a public GitHub repository named `CR7-Football-Legacy`.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment link to appear.

## Important note
This is an unofficial fan project and is not affiliated with Cristiano Ronaldo, his representatives, or any football club. It is a legacy appreciation concept, not a claim that Ronaldo has retired. Check current official sources before adding career status or statistics.
