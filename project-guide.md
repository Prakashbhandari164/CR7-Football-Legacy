# Project Guide

## Purpose
A fan-made digital tribute highlighting the work ethic, career journey and memorable celebration associated with CR7.

## Files
- `index.html`: page structure and written content
- `style.css`: responsive black-and-gold visual design
- `script.js`: reserved for future interactive enhancements
- `assets/cr7-siuuu-animation.gif`: six-frame looping celebration animation
- `assets/cr7-siuuu-spritesheet.png`: source sprite sheet used to create the GIF

## Customization
Edit the text in `index.html`, adjust colors in the `:root` section of `style.css`, and replace assets only with images you have permission to use.

## GitHub Pages
Upload the project to a public repository, then enable Pages from the `main` branch and root folder in repository Settings.
